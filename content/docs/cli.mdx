## init

Set up your project for Neobrutal UI. Creates components.json, installs dependencies, and adds utilities.

<CliTabs command="init" />

Use **-y** to skip prompts.

## add

Add components to your project. Resolves dependencies automatically.

<CliTabs command="add button dialog" />

Use **-a** for all components, **-o** to overwrite existing files.

## update

Update installed components and their registry dependencies. New component files and required packages are added automatically.

<CliTabs command="update button" />

Use **-a** to update everything installed, **--dry-run** to preview changes, or **-f** to skip confirmation.

## list

Display all available components.

<CliTabs command="list" />

## diff

Compare local components with the registry to check for updates.

<CliTabs command="diff button" />

## Configuration

The **components.json** file configures component paths and import aliases.

<CodeBlock code='{"tailwind": {
    "css": "app/globals.css"},
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils"}
}' language="json" />
